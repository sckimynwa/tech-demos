# Sample corpus attribution

- `audio/jfk.wav` — public-domain JFK inaugural excerpt, same file as [Xenova/transformers.js-docs](https://huggingface.co/datasets/Xenova/transformers.js-docs) (`jfk.wav`). Used because the official EmbeddingGemma 2 transformers.js snippet retrieves speech with the query “a president's speech about serving your country”.
- `images/*.jpg` — synthetic photos generated for this demo (cats, Mars, sea turtle, pour-over coffee).
- notes and `code/binary-search.ts` — written for this demo.
